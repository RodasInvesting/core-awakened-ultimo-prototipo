# CORE AWAKENED — Prototipo 60

## Enfoque
Build centrada en presencia física del combate, sin cambiar la mecánica central de 3 cargas de CORE.

## Cambios
- Avance automático muy corto al iniciar un puñetazo/patada cuando el rival está cerca: transferencia de peso hacia el objetivo sin teletransportar ni atravesar.
- Se conserva el footwork manual durante el ataque con flechas.
- El impulso del golpe se amortigua cuando no se mantiene una dirección, evitando deslizamientos largos.
- Aterrizaje con pequeña transferencia de velocidad horizontal para dar sensación de peso.
- Cámara de combate con un look-ahead sutil hacia la dirección de los ataques.
- Zoom de combate ligeramente más contenido cuando ambos luchadores se desplazan a alta velocidad para mantenerlos bien encuadrados.
- Se mantienen intactos CORE 0/3 → Poder → Furia → Absoluto.

## Controles
- Flechas: movimiento / salto / bloqueo
- X: puñetazo
- C: patada
- Z: poder cuando CORE está completo
- Q/W/E/R/T/Y/U: cambiar luchador del jugador
- 1–6: cambiar rival IA

## Nota de validación
El proyecto fue revisado estáticamente y empaquetado. La ejecución final debe probarse en Godot 4.3 en el entorno del proyecto.
