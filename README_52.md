# CORE AWAKENED — Prototipo 52

Base: Prototipo 51.

## Cambios
- Reacción ambiental coordinada durante impactos fuertes: partículas cercanas, piso e iluminación.
- La activación de Poder/Furia y el Absoluto ahora provocan una respuesta breve del escenario: pulso de fondo, luz y onda sobre el piso.
- El impacto de un Poder y del Absoluto incorpora una onda de choque local además de chispas, hit-stop y retroceso.
- La pose durante una secuencia especial tiene una anticipación corporal más firme y orientada hacia el rival.
- La deformación visual durante impactos normales se redujo para evitar cualquier sensación de encogimiento; la escala base permanece estable.
- Se mantiene el sistema CORE 0/3 → Poder → 1/3 → Furia → 2/3 → Absoluto → victoria.

## Prueba recomendada
1. Probar un golpe fuerte y observar la respuesta de piso/atmósfera.
2. Ejecutar un Poder con Kai, Helena y Magnus y observar que el póster sigue detrás del luchador y que el escenario responde.
3. Probar el Absoluto y comprobar el impacto físico, la onda de choque y la iluminación.
