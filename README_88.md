# CORE AWAKENED — Prototipo 88

## Intro oficial del desarrollador

Al iniciar el juego ahora se reproduce una presentación del estudio antes de la escena principal.

- Logo oficial: `assets/branding/rrodass_estudio.jpeg`
- Audio de intro: `assets/sonidos/intro_estudio.mp3`
- Escena inicial: `scenes/IntroEstudio.tscn`
- Script: `scripts/intro_estudio.gd`

### Secuencia
1. Fondo azul oscuro.
2. El logo aparece lentamente con un zoom muy sutil.
3. El audio entra con fundido suave.
4. El logo permanece visible unos segundos.
5. Imagen y audio se desvanecen.
6. El juego continúa en `Main.tscn`.

La intro se puede omitir después de 1.2 segundos con teclado, mouse o mando para facilitar pruebas.
