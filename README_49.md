# CORE AWAKENED — Prototipo 49

## Objetivo de esta build
Corregir la presentación de especiales/remates/absoluto para que el luchador ejecute físicamente el golpe y la ilustración grande quede detrás como refuerzo cinematográfico, no como sustituto del personaje.

## Cambios
- Bloqueo cinematográfico duro durante especial, rematador y absoluto: sin caminar, deslizarse ni caer por gravedad.
- Alineación automática hacia el rival antes del especial.
- El último frame de puñetazo se usa como pose heroica del lanzamiento.
- El póster queda detrás del luchador mientras este permanece visible.
- El primer especial aplica impacto físico real durante la pose cinematográfica.
- El especial de las secuencias de 2ª y 3ª carga también aplica impacto físico.
- Rematador y Absoluto conservan el cuerpo visible y la pose final durante el póster.
- CORE 0/3 -> 1/3 -> Furia -> 2/3 -> Absoluto -> victoria se mantiene intacto.
