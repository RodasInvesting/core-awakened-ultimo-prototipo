INPUT DELAY DE QA
Este primer PASS usa 4 ticks (~67 ms a 60 Hz).
El input local se captura para un tick futuro y tiene 4 ticks para llegar al rival.
En localhost/LAN esperamos 0 paquetes tardíos.

Si un paquete llega tarde:
- 14D1 usa temporalmente el último frame remoto;
- lo registra como REMOTE INPUT LATE;
- NO se certifica rollback remoto todavía.
La corrección de inputs tardíos mediante rollback es PASS 14D2.

BARRERA MAIN
Ambas instancias pueden cargar a velocidades diferentes.
NetworkManager espera MAIN LISTO de ambos peers y recién entonces emite COMBATE GO.
En COMBATE GO:
- ambos resetean RNG a la misma seed;
- ambos arrancan tick online 0;
- recién entonces comienza READY/FIGHT.
