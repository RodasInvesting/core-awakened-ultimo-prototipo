# CORE AWAKENED — Prototipo 73 — Living Arena

Base: Prototipo 72 (Physical Combat).

Cambios principales:
- Halos de contacto dinámicos bajo cada luchador, ligados a su elemento, movimiento, ataque y carga de CORE.
- Ningún efecto nuevo modifica la escala del personaje.
- El escenario ahora recibe flashes de energía durante poderes/remates sin tapar la pelea.
- Parallax vertical y horizontal más profundo, ligado al movimiento real de cámara.
- Impactos fuertes generan una ráfaga ambiental que desplaza suavemente las capas cercanas.
- Microfragmentos/partículas elementales nacen en el punto de choque y desaparecen rápido.
- La atmósfera cercana reacciona al golpe y vuelve progresivamente a su posición.
- Se mantiene intacto el sistema CORE, recarga, zoom, combos, proporciones y Absoluto del Prototipo 72.
