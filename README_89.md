# CORE AWAKENED — Prototipo 89

Fase de flujo completo y modo Arcade.

Incluye:
- Intro oficial RrodasS estudio -> portada del juego.
- Portada CORE AWAKENED con Modo Arcade, Batalla rápida y Salir.
- Música de portada y sonido START.
- Selector visual de los 7 guerreros usando el arte oficial aportado.
- Música propia del selector.
- Pantalla VS antes de cada combate.
- Modo Arcade: elegís un guerrero y enfrentás a los otros 6 en orden aleatorio.
- Cada combate Arcade usa el escenario correspondiente al rival.
- Progreso de torneo, derrota, reintento y coronación de campeón.
- Música especial para la última pelea Arcade.
- SFX de derrota y transición de nivel.
- Batalla rápida vs IA con rival aleatorio.

El sistema de combate, escenarios vivos y banco de audio de prototipos anteriores se conserva.
