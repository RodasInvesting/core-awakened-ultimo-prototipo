# Prototipo 84 — Escenarios actualizados

Se reemplazaron los fondos de batalla del juego por una nueva colección de escenarios,
asignados según el color/energía principal de cada personaje:

- Kai -> templo místico nocturno violeta
- Helena -> santuario del dragón rosa al atardecer
- Fang -> templo ígneo de tigres y portal de fuego
- Cibor-X -> laboratorio/ reactor tecnológico azul
- Kali -> arena tóxica del guardián escarabajo
- Aethel -> arena celestial entre islas flotantes
- Magnus -> arena mística del guardián de piedra

Los fondos se mantuvieron en formato 1280x720 para respetar la lógica actual del prototipo.
