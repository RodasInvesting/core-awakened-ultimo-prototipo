# CORE AWAKENED — Prototipo 89.10

## Ajustes aplicados

### 1) Pósters VS / NEXT LEVEL mejor encuadrados
- Se corrigió la presentación VS para que los pósters no queden demasiado zoom.
- Cada lado ahora usa:
  - un fondo cubierto y oscurecido para llenar limpio la pantalla
  - una capa principal centrada con escala controlada por personaje
- Resultado: se leen mejor las caras, ojos y nombres antes de la pelea.

### 2) Bug del rival quieto frente al poder especial
- Se corrigió el comportamiento donde el rival quedaba parado mirando el poder.
- Ahora, durante la cinemática del especial/rematador/absoluto, el rival entra enseguida en pose de **golpe recibido**.
- La reacción física fuerte (derribo/desplazamiento real) sigue ocurriendo al conectar el impacto final, pero visualmente ya no queda "quieto" delante del poder.
