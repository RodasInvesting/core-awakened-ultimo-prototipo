CORE AWAKENED 91.02.05 — DASH / BACK DASH VISUAL CONSISTENCY

OBJETIVO ÚNICO DE ESTA BUILD
- Mantener visible la pose dedicada de carrera/dash mientras dura un dash hacia delante.
- Mantener visible la pose de evasión/back dash mientras dura un dash hacia atrás.
- Durante el acercamiento automático de CORE II y CORE III, mostrar el sprite de dash hacia delante en vez de parado/caminata.

IMPLEMENTACIÓN
- Sólo se modifica scripts/main.gd.
- Se crea en runtime un Sprite2D gemelo de PRESENTACIÓN por Fighter cuando hace falta.
- El sprite real sigue siendo actualizado normalmente por Fighter y no se modifica su texture/scale/position.
- El gemelo se apaga al terminar el dash o comenzar un ataque/reacción.
- Durante CORE II/III el guard fuerza visualmente CARRERA hacia el rival; no reutiliza un posible estado histórico de back dash.
- El guard queda apagado durante catch-up rollback.

NO TOCADO
- scripts/fighter.gd
- scripts/perfect_block_90_1.gd
- scripts/rollback_snapshot.gd
- física, velocidad, duración de dash, hitbox, pushbox, daño, hitstun, CORE FSM.
- superposición corporal/contact spacing: queda deliberadamente para el siguiente pase.
