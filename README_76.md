# Prototipo 76 — Recarga antes del avance

Cambios principales:
- En carga 2 y carga 3 la **recarga de energía ocurre primero en la posición actual** del luchador.
- Recién después de la recarga el personaje **avanza hacia el rival** e inicia el combo automático.
- Se redujo la escala heroica de `recarga.png` para que no tape al oponente ni se salga de pantalla.
- El aumento de tamaño del atacante durante el combo se bajó a un 4%.
- No se modificó la escala del rival al recibir golpes.
