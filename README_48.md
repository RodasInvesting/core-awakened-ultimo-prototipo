CORE AWAKENED - PROTOTIPO 48

Cambios principales:
- Tamaño visual normal unificado en 255 px de altura visible para todos los luchadores.
- Las poses de puño/patada ya no recalculan la escala para evitar el efecto de encogimiento durante combos.
- Squash/stretch reducido para conservar una silueta estable.
- Se eliminó el tinte artificial del sprite durante golpes y Furia; los colores se conservan en el arte y los efectos.
- Especial/rematador/Absoluto ahora muestran el póster detrás del luchador, sin reemplazarlo.
- Los poderes tienen impacto físico real a distancia, con hit-stun, knockback y chispas.
- Rematador produce reacción física real antes de la ilustración.
- Absoluto produce un impacto físico real durante la cinemática y luego el sistema existente de main.gd ejecuta la finalización.
