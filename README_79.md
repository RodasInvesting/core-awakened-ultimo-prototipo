# Prototipo 79 — Derribo especial tras remates

Objetivo de esta fase:
- Que el final del combo especial tenga más peso y lectura.
- En la **2da carga** el rival sale despedido hacia atrás, cae acostado y luego se levanta.
- En la **3ra carga / absoluto** el rival sale aún más despedido y queda acostado.

Cambios principales:
- **Nuevo derribo especial** con lanzamiento horizontal + vertical.
- **Aterrizaje acostado** usando la pose `derribado`.
- **Recuperación automática** en el rematador normal (2da carga).
- **Caída definitiva** en el absoluto (3ra carga), previa al cierre de la pelea.
- El personaje derribado queda bloqueado mientras vuela / cae / permanece tendido.
