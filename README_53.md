# CORE AWAKENED — Prototipo 53

Mejoras principales:

- Poder 1 y Poder 2 ahora se muestran más grandes y claramente detrás del luchador.
- El póster se desplaza ligeramente hacia atrás y entra con una pequeña escala cinematográfica.
- Combo automático: antes de cada golpe, el atacante se acerca físicamente al rival y queda dentro de distancia de impacto.
- El avance del combo automático funciona incluso durante la secuencia cinematográfica, donde el movimiento normal queda bloqueado.
- Se mantiene el golpe físico real, hit-stop, retroceso, partículas, piso reactivo y el sistema CORE 0/3 → Poder → Furia → Absoluto.
