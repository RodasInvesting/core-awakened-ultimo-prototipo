# Prototipo 78 — Contacto corporal y retroceso limpio

Objetivo de esta fase:
- Evitar que los luchadores se crucen o queden uno “metido” dentro del otro al conectar golpes.
- Lograr que el impacto se sienta sobre el cuerpo del rival, con un retroceso visual inmediato.

Cambios principales:
- **Separación contextual entre luchadores**: cuando hay ataque activo, bloqueo o hit-stun, la distancia mínima entre cuerpos sube automáticamente.
- **Contacto post-golpe**: al conectar, el defensor recibe un pequeño retroceso instantáneo antes del empuje total, y el atacante cede levemente.
- **Footwork más seguro en ataque**: el acercamiento durante golpes frena antes para no entrar demasiado en el cuerpo rival.
- **Sin cambios de escala**: se preserva el tamaño correcto de los sprites.
