CORE AWAKENED — PROTOTIPO 62

Base: prototipo 61

FASE 62 — Carrera por doble pulsación de dirección
- Doble toque de ← o → dentro de una ventana corta activa una carrera mientras la dirección se mantenga presionada.
- La carrera aumenta la velocidad máxima aproximadamente un 52% respecto de la caminata normal.
- Se corta al soltar la dirección o cambiar de sentido.
- La carrera conserva la aceleración/fricción existentes y no altera el tamaño físico del luchador.
- Postura ligeramente inclinada hacia adelante y mayor sensación de inercia durante la carrera.
- Compatible con el footwork y los golpes normales sin tocar el sistema CORE 0/3 -> Poder -> Furia -> Absoluto.
