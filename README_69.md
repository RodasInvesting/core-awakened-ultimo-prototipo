# Prototipo 69 — Correcciones visuales de recarga + cámara

Se aplicaron las siguientes mejoras sobre el prototipo anterior:

1. **Poses de recarga reemplazadas**
   - Se actualizaron `recarga.png` de Fang, Magnus, Aethel, Kali, Kai, Helena y Cibor-X con las imágenes nuevas enviadas.

2. **Zoom cinematográfico corregido**
   - El zoom previo al combo ya no se va hacia atrás.
   - Ahora se acerca al personaje que carga energía, pero mantiene visible también al rival.
   - El remate absoluto usa el mismo criterio para no sacar del cuadro a ninguno de los dos luchadores.

3. **Oscurecimiento de escena mejorado**
   - Se atenúan fondo, capas del escenario, partículas y piso.
   - El rival también se oscurece levemente para resaltar la pose de recarga.

4. **Mejor proporcionalidad visual entre sprites**
   - Se ajustó la normalización de escala de poses con auras/efectos grandes.
   - Esto compensa especialmente recargas, golpes nuevos y reacciones nuevas al recibir golpes.
