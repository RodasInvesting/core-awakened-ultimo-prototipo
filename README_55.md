# CORE AWAKENED — Prototipo 55

Fase 55 — Expresividad corporal y facial procedural.

Cambios principales:
- Respiración en reposo ligeramente más perceptible sin cambiar la escala base del luchador.
- Micro transferencia de peso durante el estado idle para que el personaje no parezca congelado.
- Parpadeo procedural sutil únicamente en reposo, con posiciones calibradas por personaje.
- La capa facial acompaña al sprite en posición, rotación y escala para mantenerse integrada con el cuerpo.
- El parpadeo se desactiva automáticamente durante caminar, ataques, bloqueo, salto, hit-stun, poderes y cinematográficas.
- No se modifica la mecánica CORE 0/3 → Poder → Furia → Absoluto.
- No se modifican las escalas físicas ni la colisión.

Nota: la apertura de boca/expresiones faciales más complejas requiere máscaras faciales específicas por personaje para evitar dibujar encima de ojos o boca de forma incorrecta. Esta build deja la base preparada con parpadeo y estados corporales antes de pasar a esa etapa.
